# Avora logo

| File | Use it on |
| --- | --- |
| `avora-logo.png` | Light backgrounds. Full logo with the "Bank Smarter. Live Better." tagline. |
| `avora-logo-white.png` | Dark or coloured backgrounds. Same logo with white text. |
| `avora-wordmark.png` | Light backgrounds, where the tagline would be too small to read. |
| `avora-wordmark-white.png` | Dark or coloured backgrounds, without the tagline. |
| `avora-mark.png` | The "A" on its own: app icon, avatars, small spaces. |

All files have transparent backgrounds. The app ships its own copies of the mark and the white wordmark in `app/assets/brand/`, and the Android launcher icon and splash in `app/android/app/src/main/res/`.

The source artwork was delivered on black. The parts of the "A" that sit on black in the original (the fold under the swoosh and the card) are kept solid so the mark looks the same on any background.
